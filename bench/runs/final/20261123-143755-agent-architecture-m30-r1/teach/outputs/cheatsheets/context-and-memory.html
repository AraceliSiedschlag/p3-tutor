Context and memory in an agent

The core terms

  • Context window: every token the model processes for one call — system prompt, history, tool definitions, tool results. Nothing outside it exists to the model right then.
  • Token: roughly a word or word-piece; the unit the context window's size limit and cost are both measured in.
  • Session: one continuous run of the assistant, from the start of a request to when it stops.
  • Context rot: recall accuracy gets worse, not better, as the context window fills with more tokens.
  • Retrieval: fetching one piece of an existing external source into context, only when needed ("just in time").
  • Notes: text the agent itself writes to storage outside the context window, so a later step or session can read it back.

What survives, and when

GapWhat carries over
Step to step, same sessionEverything: the program resends the full history each call. The model itself keeps nothing.
Session to sessionNothing, automatically. Only what was written to a file (or similar storage) and deliberately read back in the new session.

Retrieval vs. notes

FeatureRetrievalNotes
SourceAn existing document or recordThe agent's own observation or decision
WrittenBefore the agent ever ranBy the agent, during an earlier step or session
MechanicallyA tool call that returns text into contextSame: a tool call that returns text into context
Both land in context the same way. The only question that tells them apart: did this text exist before the agent got involved (retrieval), or did the agent write it itself (a note)?

Why more context isn't automatically better

  • Context rot: recall drops as the window fills with irrelevant text.
  • Every token — history, a retrieved chunk, a loaded note — costs the same, whether or not it helps the answer.

Common mix-ups

The model "remembers" what you just told it, the way training works. — No: it only has that text because it's sitting in the resent context; the model's weights never change mid-conversation.
A new session should continue the last one, like a resumed phone call. — No: a new session's context window starts empty, unless something was explicitly saved and reloaded.
Retrieval and notes are the same feature. — Mechanically yes, but the source differs: an existing document vs. the agent's own record.
A bigger context window means you can skip memory design. — No: context rot and per-token cost both still apply, however large the window.
