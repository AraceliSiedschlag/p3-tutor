Context and memory in an agent

One page. From lesson 0001 (objective O3).

Terms

Token
A small chunk of text, often a piece of a word, that the model reads and writes.
Context window
All the tokens the model can reference for one turn: system prompt, conversation so far, tool definitions and results, and the output it's writing. Fixed size, shared between input and output. Separate from training.
Context rot
Accuracy and recall degrade as irrelevant tokens pile up in context — before the window is even full. More context is not automatically better.
Memory (notes as memory)
Information the agent deliberately writes to storage outside the context window, and reads back in a later session. Nothing crosses sessions unless it was saved this way.
Retrieval
Searching a large external source for just the part relevant to the current request, and adding only that part to the prompt — not the whole source.

The three-bucket sort

BucketAskExample
Context windowWas it actually sent to the model this turn?This turn's question, a tool result just returned
Saved noteIs it a durable fact from a session that's already gone?A student's training-completion date
RetrievalIs it one slice of a large external source, needed on demand?One section of an 80-page manual

Fixed-size limits, two different failures

SituationWhat happens
Input alone is already over the token limitRequest fails outright, before any output
Window fills up while the model is still writingOutput stops mid-sentence
Window has room left, but is full of irrelevant tokensContext rot — accuracy degrades anyway

Common mix-ups

A bigger context window always gives a better answer. (No — context rot.)
The assistant remembers earlier sessions like a person would. (No — context windows start empty every session; only saved notes cross over.)
The context window and memory are the same thing. (No — the window is temporary and per-session; a note is durable storage outside it.)
Only the latest tool result matters mid-session. (No — by default every earlier turn in the session stays in context.)
Retrieval means handing the model the whole document. (No — only the matching slice gets pulled in.)
