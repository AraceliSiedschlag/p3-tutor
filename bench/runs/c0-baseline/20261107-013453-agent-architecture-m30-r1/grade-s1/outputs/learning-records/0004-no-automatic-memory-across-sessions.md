# Riley thinks the model remembers things across sessions on its own

On quiz 0001 q6, after correctly describing how the model picks a tool from its description, Riley added that the model "also remembers on its own which tool it picked for questions like that in earlier sessions" (M3). The same misconception is option b of q1, which Riley correctly ruled out there, so the belief is inconsistent rather than settled.
A model call starts fresh every time; nothing carries over between sessions unless the program explicitly stores it and puts it back into a later input. This is exactly the gap the mission's next topic, context and memory, needs Riley to see clearly, since the makerspace assistant must remember each student's training status deliberately, not assume the model will.

**Evidence:** quiz 0001, submission s1, item q6 (grades/0001-s1.json); contrast with q1, answered correctly.

**Implications:** Open the context-and-memory lesson by drawing the line between "the program stores and re-supplies something" and "the model remembers on its own" before introducing memory mechanisms, since Riley needs the second one ruled out first.
