# Misconception: a stuck agent will eventually fix itself

Riley chose "left to run longer, it will eventually fix the bug" for a coding agent stuck repeating the same failing edit for 40 steps, rather than a step limit.
This is M6: treating more steps as inherently more progress, when a loop repeating the same action against the same feedback is not gaining anything a stopping condition wouldn't catch sooner. This is directly relevant to the mission, since the makerspace assistant will need explicit stopping conditions of its own.

**Evidence:** quiz 0001, submission s2, item q3.
