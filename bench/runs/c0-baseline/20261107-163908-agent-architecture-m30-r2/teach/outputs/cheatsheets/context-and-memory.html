Context, memory and retrieval

One page. From lesson 1, objective O3.

The three ideas

IdeaWhat it isLasts
Context windowEverything handed to the model for one call: instructions, conversation so far, tool results so far. Fixed token limit; grows within a session, never shrinks on its own.One session, then discarded
Persistent memoryStorage outside the model — a file, a database row, a note — that the program writes to and reads from.Until overwritten or deleted
RetrievalThe search step that finds the relevant piece of a larger store (a manual, a set of records) and loads just that piece into this call's context window.Happens fresh each time it runs

Where does this information belong?

  1. Needed only for this one exchange, already in the conversation? → It's already in the context window; nothing to do.
  2. Needs to be true next session, next week, or for a different student's assistant session entirely? → Write it to persistent memory (a file or record) when it becomes true.
  3. Lives in a document too big to paste in every time (a manual, a roster)? → Store it outside the context window and use retrieval to pull in only the matching piece, on demand.
  4. Session running long and close to the limit, but not done? → Compact: summarize what matters so far, continue from the summary.

Key terms

  • Token — the unit text is measured in for the context window and for cost; roughly three-quarters of a word.
  • Context rot — recall of any one fact gets less reliable as the context window fills up, even before the hard limit is hit.
  • Compaction — summarizing a long run so far into a shorter note, then continuing from the note instead of the full transcript.
  • Chunk — a piece (a page, a section) that a large document is split into for retrieval, so a search can match and load just that piece.
  • Structured note-taking — an agent writing short, readable notes to persistent storage as it works, instead of (or alongside) a database.
The one mix-up to watch for: the model does not automatically remember past sessions, other students, or anything not handed to it this call. If it "knows" something from before, a program retrieved it from somewhere and put it in context on purpose.
