Context and memory

Terms

Token
The small chunk of text (a word piece, a punctuation mark) a model reads or writes one at a time; how providers usually price a call.
Context window
All the text assembled for one model call — system prompt, tools, conversation, tool results, output — capped in tokens. The model's "working memory" for that call only.
Context rot
Accuracy and recall degrade as a context window fills with tokens. More context is not automatically better.
Memory
A fact the program writes somewhere durable, outside the window, the moment it becomes true, and reads back into a later call. Not automatic — a deliberate write, then a deliberate read.
Retrieval
Searching a large, pre-existing source (a manual) for the few passages relevant to this question, and handing the model only those, instead of the whole source.
Structured note-taking
An agent authoring short notes as it works (a to-do list, a tally, a date) and reloading them later — memory the agent itself produces, not a pre-existing document.

What's kept, when

TimeframeDefaultHow to change it
Within one run (same loop)Everything so far stays in context; it only growsAdd a stopping condition, or trim / summarize old steps
Across sessionsNothing; a new call starts blank except system prompt + toolsWrite a fact to storage when it becomes true; read it back in when relevant

Memory, retrieval, or neither?

  1. Is this fact already written somewhere in bulk (a manual, a policy doc)? → retrieval: search it, return the relevant chunk.
  2. Is it true about one specific student, project, or machine, discovered at a moment that will not repeat on its own? → memory: write it once, reload it later.
  3. Is it cheap to just ask again, or already given in this message? → skip: don't persist it.

Cost rule of thumb

Every token in the context window is paid for on every call it appears in. A loop that never drops old tool results pays for its whole history again at each step. A tool that returns a whole document instead of a snippet pays for the parts nobody asked about — every time.
