# Riley assumes the model automatically remembers past sessions (M3)

On quiz 0001 (submission s1) q6, Riley correctly described how a model picks a tool from its description, then added, unprompted, that the model "remembers on its own which tool it picked for questions like that in earlier sessions." The model has no memory beyond what is put into a given call's input; any memory across sessions has to be built and fed in by the program. This is the exact misconception the context-and-memory session, next in the mission, needs to address head-on, since the makerspace assistant must remember each student's training status between visits and that will not happen automatically.

**Evidence:** quiz 0001, submission s1, item q6.

**Implications:** Open the context-and-memory session by naming this belief directly, before introducing how memory is actually implemented.
